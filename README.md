# Ля Вуа Лакте — лендинг

Сайт молочного завода ОсОО «Ля Вуа Лакте» (бренд «Токтогул сүт»).

Статический лендинг в `public/`, раздаётся маленьким Node-сервером без зависимостей.
Деплой — Railway (автоматически при пуше в `main`).

## Запуск локально

```
npm start
```

Откроется на http://localhost:3000 (порт берётся из `PORT`).

## Структура

- `public/index.html` — страница
- `public/styles.css`, `public/script.js` — стили и скрипт
- `public/img/` — сюда класть реальные фото (см. ниже)
- `server.js` — статический сервер (Railway запускает через `npm start`)

## Фото вместо иллюстраций

Сейчас продукция нарисована SVG-иллюстрациями. Чтобы заменить их настоящими фото,
положите файлы в `public/img/` — страница подхватит их сама, правок в коде не нужно:

| Файл (webp, jpg, jpeg или png) | Где показывается |
| --- | --- |
| `about` | блок «О заводе» |
| `cheese` | карточка «Сыры» |
| `yogurt` | карточка «Йогурты» |
| `butter` | карточка «Сливочное масло» |
| `curd` | карточка «Творог и другое» |

Например: `public/img/cheese.webp`. Лучше квадратные или вертикальные кадры от 1200 px.
