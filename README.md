# Ля Вуа Лакте — лендинг

Сайт молочного завода ОсОО «Ля Вуа Лакте» (бренд «Токтогул сүт»).

Статический лендинг в `public/`, раздаётся маленьким Node-сервером без зависимостей.

## Запуск локально

```
npm start
```

Откроется на http://localhost:3000 (порт берётся из `PORT`).

## Структура

- `public/index.html` — страница
- `public/styles.css`, `public/script.js` — стили и скрипт
- `public/img/` — сюда класть фото (в `index.html` у hero есть комментарий, где подставить)
- `server.js` — статический сервер (Railway запускает через `npm start`)
