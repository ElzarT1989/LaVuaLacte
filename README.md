# Ля Вуа Лакте — лендинг

Сайт молочного завода ООО «Ля Вуа Лакте» (бренд «Токтогул сүт»).

Одна страница: полноэкранная 3D-история «Путь молока» — молоко льётся, свёртывается в творог,
прессуется в головку сыра, созревает в погребе и превращается в продукцию. История идёт
по прокрутке. Ниже — блоки «О заводе», «Продукция», «Контакты».

Сайт раздаётся маленьким Node-сервером без зависимостей. Деплой — Railway (автоматически при пуше в `main`).

## Запуск локально

```
npm start
```

Откроется на http://localhost:3000 (порт берётся из `PORT`).

## Как устроено

3D нарисовано на чистом WebGL2, без библиотек и без картинок: каждая сцена — это шейдер,
поэтому всё процедурное. Сцена 0 («текучее молоко») — карта высот с вихрем, остальные — raymarching
по полям расстояний.

- `public/index.html` — разметка, тексты глав, секции под историей
- `public/site.css` — стили (имя менялось намеренно: старый styles.css застрял в кэше браузеров)
- `public/js/shaders.js` — GLSL: 4 сцены (текучее молоко, творог/пресс/сыр, погреб, продукция) и пост-обработка
  (блум, тональная компрессия, FXAA, молочная «шторка» между сценами)
- `public/js/stage.js` — WebGL: сцены → HDR-буфер → пост-проход, адаптивное разрешение
- `public/js/main.js` — прокрутка → прогресс истории, тексты глав, меню, ссылки WhatsApp
- `server.js` — статический сервер

Если WebGL2 недоступен, страница показывает обычную версию без 3D (`html.no-gl`).
Анимация сама снижает разрешение, если видеокарта не тянет; при `prefers-reduced-motion` время замирает.

### Производительность шейдеров

Сцены компилируются по одной в фоне, пока пользователь читает первый экран. На Windows (ANGLE/D3D11)
компилятор FXC очень болезненно относится к шумам и многократно вызываемой `map()`: раньше сцена 1
собиралась ~15 с и драйвер сбрасывал WebGL-контекст (страница падала в версию без 3D). Поэтому:
в `map()` — только дешёвый синусный шум (`fbm` — только в шейдинге и 2-октавный `fbmL`),
отражения в полу идут по упрощённой карте `mapR`, освещение вызывается из одного места.
Замер: сцены собираются за 0,06 / 2,7 / 1,3 / 2,2 с. При добавлении в шейдер новых `fbm`/`map()` проверяйте время.
Если контекст всё же теряется, страница один раз перезагружается, а затем показывает обычную версию.

### Отладка

Параметры в URL: `?p=0.3` — зафиксировать прогресс истории (0…1), `?t=2.5` — зафиксировать время,
`?scale=0.5` — фиксированный масштаб рендера, `?debug` — показать лог ошибок шейдеров.
В консоли: `LVL.go(0.3)`, `LVL.stats()`.
