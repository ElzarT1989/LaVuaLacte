# Ля Вуа Лакте — лендинг

Сайт молочного завода ООО «Ля Вуа Лакте» (бренд «Токтогул сүт»).

Одна страница: полноэкранная 3D-история «Путь молока» — молоко льётся, свёртывается в творог,
прессуется в головку сыра, созревает в погребе и превращается в продукцию. История идёт
по прокрутке. Ниже — блоки «О заводе», «Продукция», «Контакты».

Сайт раздаётся маленьким Node-сервером без зависимостей. Деплой — Railway (автоматически при пуше в `main`).

## Запуск локально

```
npm start
```

Откроется на http://localhost:3000 (порт берётся из `PORT`).

## Как устроено

3D нарисовано на чистом WebGL2, без библиотек и без картинок: каждая сцена — это шейдер,
поэтому всё процедурное. Сцена 0 («текучее молоко») — карта высот с вихрем, остальные — raymarching
по полям расстояний.

- `public/index.html` — разметка, тексты глав, секции под историей
- `public/site.css` — стили (имя менялось намеренно: старый styles.css застрял в кэше браузеров)
- `public/js/shaders.js` — GLSL: 4 сцены (текучее молоко, творог/пресс/сыр, погреб, продукция), `RESOLVE` (накопление кадров)
  и `POST` (бикубическое увеличение, резкость, блум, тональная компрессия, молочная «шторка» между сценами)
- `public/js/stage.js` — WebGL: сцена → накопление → пост-проход, адаптивное разрешение
- `public/js/i18n.js` — тексты на 4 языках (кыргызский — основной, русский, французский, английский)
- `public/js/main.js` — прокрутка → прогресс истории, тексты глав, меню, ссылки WhatsApp
- `server.js` — статический сервер: brotli/gzip из памяти, ETag и 304

Если WebGL2 недоступен, страница показывает обычную версию без 3D (`html.no-gl`).
Анимация сама снижает разрешение, если видеокарта не тянет; при `prefers-reduced-motion` время замирает.

### Графика: чёткость и плавность

Конвейер кадра: сцена рисуется в HDR-буфер (RGBA16F) с субпиксельным дрожанием камеры (Halton 2,3) →
`RESOLVE` накапливает кадры (TAA: история ограничивается по соседним пикселям, поэтому нет «шлейфа»;
при прокрутке или движении мыши вес нового кадра растёт) → `POST` увеличивает результат до размера холста
бикубикой Catmull-Rom, слегка поднимает резкость (ограничено соседями — без ореолов), добавляет блум
(4 выборки на уровень, без блочности), тон, виньетку и дизеринг. Сглаживание рёбер даёт накопление, а не FXAA,
поэтому картинка не мылится.

- Холст — CSS-размер × min(devicePixelRatio, 1.5), не больше ~2 Мп (1,3 Мп на телефонах); размер меняется с задержкой 140 мс.
- Разрешение сцены — по ступеням (0,5 … 1,0 от холста), отдельно для каждой сцены; падает при кадрах >25 мс,
  растёт только когда все шейдеры уже собраны. Единичные подвисания драйвера не учитываются.
- Бесшовность: каждый шейдер после сборки один раз прогоняется по буферу 8×8 (драйвер заканчивает компиляцию заранее).
  Если следующая сцена ещё не готова, прокрутка упирается в молочную шторку и плавно её удерживает, а не показывает чужую сцену.
- Сервер сжимает текст (br/gzip) и отдаёт ETag; HTML/CSS/JS кэшируются с обязательной проверкой, шрифты Google подгружаются без блокировки.

### Производительность шейдеров

Сцены компилируются по одной в фоне, пока пользователь читает первый экран. На Windows (ANGLE/D3D11)
компилятор FXC очень болезненно относится к шумам и многократно вызываемой `map()`: раньше сцена 1
собиралась ~15 с и драйвер сбрасывал WebGL-контекст (страница падала в версию без 3D). Поэтому:
в `map()` — только дешёвый синусный шум (`fbm` — только в шейдинге и 2-октавный `fbmL`),
отражения в полу идут по упрощённой карте `mapR`, освещение вызывается из одного места.
Замер: сцены собираются за 0,06 / 2,7 / 1,3 / 2,2 с. При добавлении в шейдер новых `fbm`/`map()` проверяйте время.
Если контекст всё же теряется, страница один раз перезагружается, а затем показывает обычную версию.

### Языки

Переключатель KY / RU / FR / EN в шапке. По умолчанию открывается кыргызский; выбор запоминается в браузере,
`?lang=fr` принудительно задаёт язык. В `index.html` у элементов стоят `data-i18n="ключ"`, сами тексты — в
`public/js/i18n.js`. Чтобы поправить перевод, достаточно отредактировать словарь (и, для кыргызского, такой же
текст в `index.html` — он показывается до загрузки скриптов). Латинское написание бренда («La Voie Lactée»,
«Toktogul süt») пока предположительное — уточнить у владельца.

### Отладка

Параметры в URL: `?p=0.3` — зафиксировать прогресс истории (0…1), `?t=2.5` — зафиксировать время,
`?scale=0.5` — фиксированный масштаб рендера, `?debug` — показать лог ошибок шейдеров.
В консоли: `LVL.go(0.3)`, `LVL.stats()`.
